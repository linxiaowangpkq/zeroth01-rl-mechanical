# Zeroth-01 V5 右臂首件包

## 结论

- X2D 与 P2S 使用**同一套 STEP/3MF**，不能为了打印机型号分叉机器人 CAD。
- 两台机器的切片、支撑、热收缩和孔补偿不是同一制造工艺，因此最终实物尺寸不保证天然相同；每台机器、每批 PA6-CF 都必须先通过 `FC01` 配合样件。
- 本包先冻结一条右臂的承力链：3 个必打件、3 个 STS3250、3 组金属输出接口。数字子装配已从 V5 occurrence manifest 提取；实体上电仍保持 `HOLD`，直到 `RIGHT_ARM_POWER_TEST_CHECKLIST.csv` 的 G00–G09 全部实测 PASS。

## 推荐首件顺序

1. 用廉价 PETG 打 `FC01`，拿真实 STS3250 检查 45.22 × 24.72 mm 壳体基准、4×M2 和输出轴中心。记录实际偏差，不要直接锉大正式件。
2. 只打 RA01–RA03。RA04 暂不打印、不参与上电。正式承力首件使用干燥 PA6-CF、0.6 mm 淬硬钢喷嘴、0.20 mm 层高、5 壁、6 层顶底、45% Gyroid。
3. 打印的 FC02/FC03 仅做配合；上电前更换为 6061-T6/POM 最终件。FDM 塑料输出桥不得进入动力扭矩链。
4. 无电干装三关节。确认 S01 是合法的反装结构：输出桥固定在 RA01，而舵机壳体随 RA02 运动；不要把 S01 壳体强行固定到 RA01。
5. S03 的壳体必须固定在真实 torso 或刚性金属台架上，整条手臂不能手持、悬空上电。
6. 执行 `RIGHT_ARM_POWER_TEST_zh.md`；通过后才镜像推进左臂和整机打印。

## 当前证据边界

- 已有：V5 精确购买件 STS3250 STEP、静态 B-Rep、URDF/MJCF、三关节父/子 link 和彩色子装配。
- 尚无：你手中这批舵机、喷丝批次、孔补偿、金属件、螺钉啮合、线束和真实载荷的实测结果。
- 当前 manifest 中三只右臂舵机的 6D 拟合残差为约 2.611–3.149 mm；清空后的 B-Rep 名义正体积干涉为 0，但这不是实际 M2 孔/壳体固定强度的签字数据，正是 FC01 与右臂首件必须先做的原因。
- 首轮可视化发现 RA04 依赖未冻结的长通孔螺栓且在无紧固件模型中表现为悬空；它已被降级为可选研究件，避免把非承力外观件误当成可上电连接。
- 所以现在可以开打右臂首件并做受控台架测试，但不能在打印前宣称“实物必然直接装上并可满扭矩运行”。
