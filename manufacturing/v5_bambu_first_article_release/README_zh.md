# Zeroth-01 v5 拓竹首件打印发布包

## 发布边界

- 状态：`FIRST_ARTICLE_PRINT_RELEASE`。
- 目标：Bambu Studio；成形空间至少 `256 × 256 × 256 mm`。适用于 P1S、X1C、A1、H2 等同级平台；**尚未针对 A1 mini 的 180 mm 平台排版验证**。
- 主打印格式：`3mf/`。每个零件的多个闭合实体会在 3MF 中独立保存。
- 可编辑母版：`step/assembly_frame/`；已摆正到打印平台的 STEP 位于 `step/print_oriented/`。
- `stl/` 只是兼容导出。`11_3215_bothflange_10...` 和 `26_torso_mounted_solid` 的多个接触实体在合并 STL 中可能显示接触边；Bambu Studio 应使用对应 3MF。
- 不包含机器专用 G-code，因为打印机型号、喷嘴、热床板、材料批次和流量标定尚未冻结。在 Bambu Studio 中选定实际机器后切片。
- 当前 CAD 静态中立位精确 B-Rep 检查为 0 个正体积干涉；打印网格门禁为 PASS。动力运动仍是 `HOLD_UNTIL_PRINTED_FIRST_ARTICLE_DRY_FIT_AND_ISOLATED_JOINT_SWEEP`。
- 当前 16×STS3250 版本只冻结为站立/步行首件。`bug.md` 已证明现有跑步策略的膝关节 p95 速度约 5.0 rad/s，超过 STS3250 声明的 3 rad/s；不得把本包宣传为可实机跑步版本。

## 推荐打印参数

### 承力件（PA6-CF）

- 文件：清单中 `part_class=STRUCTURAL` 的 22 件。
- 喷嘴：0.6 mm 淬硬钢；层高 0.20 mm。
- 壁数：5；顶/底：6 层；填充：45% Gyroid。
- 打印前按材料厂家要求彻底干燥；打印过程中保持干燥供料。
- 仅在超过 50° 且确有需要的位置手绘支撑。舵机槽、轴承/推力面、螺钉贴合面和 PCD14 接口面尽量不生成支撑。
- 首层完成后检查翘边；结构件不得用 PLA 替代。

PA6-CF 通常为黑色。整机要白色时，先完成装配与运动首件，再对外露结构件使用尼龙兼容底漆和白色面漆。白色 PA6-GF 虽可采购，但层间冲击指标与 PA6-CF 不同，不能未经同批试样拉伸/冲击和关节疲劳验证直接替换承力材料。

### 外观和维护件（PETG-HF）

- 白色：头部前壳、后壳；黑色：面罩；其余服务托架颜色不限。
- 喷嘴：0.4 mm；层高 0.20 mm；4 壁；顶/底 5 层；25–30% Gyroid。
- PETG 也必须干燥。头壳装配孔和摄像头开口先用去毛刺刀手工清理，不要直接扩大 CAD 孔径。

## 首件顺序

1. 先打印 `fit_check_only/01_sts3250_4xm2_first_article_face_gauge.3mf`，用一只真实 STS3250 验证 4×M2 后盖孔、输出轴位置和壳体外形。
2. 打印一套最典型关节：一个腿部承力架、一个肩部承力架、一个脚部件和 PCD14 塑料样件。塑料 PCD14 桥/环仅用于配合检查，不能进入动力扭矩链。
3. 记录实际孔径、轴心偏差、装配间隙、螺钉有效啮合长度和材料收缩；若需要补偿，只修改源 STEP/Python 后重新生成全包。
4. 样件通过后打印 torso、左右腿、左右臂和内部托架；头壳最后打印。
5. 去毛刺、热熔螺母安装和无舵机干装后，再装 1 个舵机做单关节限位慢扫；每次只使能一个关节。
6. 16 个关节全部完成实体零位、方向、ID、背隙、线束余量和机械硬挡检查后，才允许低扭矩站立测试。

## 质量和耗材

- 30 个打印源件的“按完全实心体积计算”材料上限约 `702.6 g`：PA6-CF 约 `602.2 g`，PETG-HF 约 `100.4 g`。这不是切片质量；45%/25–30% 填充后的实际用量通常更低，但支撑、裙边、流量标定和失败余量会增加耗材。
- 采购建议：PA6-CF 1 kg、白色 PETG-HF 1 kg、黑色 PETG-HF 0.25–1 kg。正式开打前以 Bambu Studio 的实际切片统计复核。
- 当前 URDF/MJCF 标称整机质量为 `2.745759 kg`。打印后必须逐 link 称重、测 COM/惯量并做 SysID，再覆盖 RL 惯性；不能把 CAD 材料上限直接写回 URDF。

## 不可打印成最终承力件的接口

`fit_check_only/02`、`03`、`04` 只用于塑料配合试装：

- 输出桥：OD 19.95 / ID 6.2 / 4×Ø3.2 on PCD14 / 厚 2.05 mm，最终建议 6061-T6 CNC 或精密板件。
- 父侧推力环：OD 25 / ID 20.4 / 厚 2 mm，最终建议 POM 或 6061-T6 精密加工。
- 髋 yaw 四套筒：OD 4 / ID 3 / 长 1.65 mm，最终使用金属精密套筒或研磨定厚件。

最终金属件以该目录 STEP 询价。未经实测，不允许用 FDM 塑料件承受 STS3250 的动力输出扭矩。

## 上电前硬门禁

- 逐关节手动全行程无卡滞，静态和运动间隙均可见；线束不经过剪切面。
- 所有输出桥、套筒、锁紧螺母和保险丝为最终件；舵机壳体固定与输出侧明确分属父/子 link。
- 3S 电池尺寸不超过 `75 × 22 × 34 mm`，极性和 XT30 插头核对；主电源有保险丝和物理急停。
- 先用限流电源和单舵机，再用双腿台架，最后才装电池整机上电。
- 当前 Z4/L3 跑步 checkpoint 禁止上机；保留 STS3250 时需重训硬件限速步行策略。
